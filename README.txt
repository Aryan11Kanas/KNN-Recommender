# Dataset Folder

Place the following two files here before running the app:

1. `movies.csv`   — contains movieId, title, genres
2. `ratings.csv`  — contains userId, movieId, rating, timestamp

## How to Download

1. Go to: https://grouplens.org/datasets/movielens/latest/
2. Download **ml-latest-small.zip**
3. Unzip it
4. Copy `movies.csv` and `ratings.csv` into this folder

That's it! Then run: `streamlit run app.py`
